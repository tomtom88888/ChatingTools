# ReplyLikeMe

A Flutter app (Android + iOS) that suggests WhatsApp replies written in *your*
texting style, learned from your own chat exports.

Your chat data never leaves the device except for the calls you make to the
OpenAI API with your own key.

Full setup, build and WhatsApp-export instructions land in this file as the app
is built out — see the sections below once the screens exist.

## Status

Work in progress. Built in order: parser + tests, OpenAI service, screens.
